# Unit 2 — From Struct to Class

This unit introduces C++ classes by moving from public structures and separate
functions to objects that combine data and behavior.

## Learning outcomes

After completing this unit, you should be able to:

- distinguish a class from an object;
- design a small public interface and protect data with private access;
- compare pass by value, pointer, and reference;
- separate a class declaration from its implementation.

## Main ideas

- Classes, objects, data members, and member functions
- Private data and public behavior
- Pass by value, pointer, and reference
- Header, implementation, and client files
