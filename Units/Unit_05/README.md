# Unit 5 — Working with Objects and Relationships

This unit examines how complete objects are passed, copied, initialized, and
connected in a multi-class application.

## Learning outcomes

After completing this unit, you should be able to:

- choose between value, reference, and `const`-reference parameters;
- apply const correctness to objects, parameters, and member functions;
- recognize copy construction and safe object return;
- use constructor initializer lists and explain initialization order;
- use static members and understand inline definitions;
- distinguish association, aggregation, and composition;
- read and draw a UML class diagram for collaborating classes.

## Main ideas

- Object parameters, references, returns, and `const`
- Copy construction and memberwise copying
- Constructor initializer lists and initialization order
- Static members and inline functions
- Composition and aggregation
- Building a multi-class music-library application
- Reading and creating UML class diagrams
