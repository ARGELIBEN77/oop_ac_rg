# Unit 7 — Inheritance and Binding

This unit builds class hierarchies and introduces the relationship between
base and derived objects, virtual functions, and runtime binding.

## Learning outcomes

After completing this unit, you should be able to:

- design a public-inheritance hierarchy that expresses an is-a relationship;
- initialize a base-class part from a derived constructor;
- apply public, protected, and private access rules;
- trace base and derived construction and destruction order;
- distinguish static type, dynamic type, and binding time;
- distinguish hiding from overriding and use `override` safely;
- explain virtual-table dispatch and constructor-time binding;
- explain and prevent slicing and unsafe base-class destruction.

## Main ideas

- Base and derived classes
- Is-a relationships, public inheritance, and substitutability
- Base initialization and access control
- Construction and destruction order
- Hiding, overriding, and virtual functions
- Static and dynamic binding and the virtual table
- Object slicing and virtual destructors
